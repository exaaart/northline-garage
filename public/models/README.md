# 3D-модель для Hero

Положите сюда файл `auto-car.glb`, и сайт автоматически покажет его вместо процедурной концепт-модели.

Требования:
- формат glTF Binary (`.glb`), допускается Draco-сжатие;
- без логотипов и шильдиков, если нет права на их использование;
- желательно до 5–8 МБ и до ~150 тыс. треугольников (на мобильных включается облегчённый режим рендера, но сам файл загружается тот же).

Модель масштабируется до длины ~4,6 м, центрируется и ставится на поворотный круг. Самая длинная горизонтальная ось считается продольной. Если машина стоит задом наперёд, поверните её в редакторе на 180° или добавьте `root.rotation.y += Math.PI` в `normalizeModel()` (`src/garage3d.js`).
